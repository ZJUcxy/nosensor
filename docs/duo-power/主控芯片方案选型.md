# 双向直流电源主控芯片方案选型

## 1. 任务目标

实现 220V 交流与 300V 直流之间的双向能量流动，并完成制动能量回馈时的 PFC 升压控制。主控需要同时覆盖采样、调制、保护、锁相和调试接口。

## 2. 选型结论

最终方案为 DSP + FPGA。订货型号、功能分配和单板拓扑见 [DSP+FPGA 双芯片方案](DSP+FPGA双芯片方案.md)。

| 工程简称 | 可订货型号 |
| --- | --- |
| 28288 | TMS320F28388DPTPS |
| K7A100 | XC7A100T-2FGG484I |

下文第 6、7 节保留选型过程中的五种对比，不再作为实施路径。实施以双芯片方案文档为准。

## 3. 电压约束

220V 交流有效值的峰值约为 311V。单相桥从 300V 直流母线逆变，最大只能达到约 212V 有效值。

若必须以满电压 220V 并网，直流母线需要抬到约 380–400V，或增加变压器。该约束影响功率拓扑，不改变下文的外设需求；PWM 仍按 6 路估算。

## 4. 功能与资源

| 功能 | 实质需求 | 关键约束 |
| --- | --- | --- |
| 母线电压检测（AMC3306） | 约 20 MHz 的 1-bit 码流，Sinc3 抽取 | 时钟必须与 PWM 载波同源，避免拍频进入采样 |
| 三路电流检测 | 隔离 Σ-Δ 采样，并带硬件过流比较 | 过流直接封波，不经过软件中断 |
| 制动能量 PFC 升压 | 电流环约 20–50 kHz，电压环数 kHz，支持双向切换 | 死区、占空比分辨率和环路延迟要稳定 |
| 防孤岛保护 | 过压 / 欠压 / 过频 / 欠频，以及主动扰频 | 判据在处理器中完成，跳闸出口走硬件 |
| 制动电阻控制 | 独立斩波 PWM，优先级高于正常调制 | 母线过压时由组合逻辑直接开通斩波 |
| ADC / PLL 检测 | 电网电压低延迟采样，SOGI-PLL 或 SRF-PLL | 锁相不使用 AMC3306。20 MHz、OSR=256 时 Sinc3 群延迟约 38 µs，会引入相位误差 |
| 六路 PWM | 双向变换约 4 路，制动 1–2 路 | 互补输出、死区、故障封波 |
| 串口调试 | 参数调整与运行信息 | 各方案均可实现 |
| JTAG 调试 | 在线仿真与下载 | 各方案均可实现 |
| SFP 调试 | 高速调试数据出口 | 见第 5 节，是方案分界点 |

AMC3306 按 1 路母线电压 + 3 路电流共 4 路估算。F28379D / F28388D 具备 8 路 SDFM，通道数量够用，比较器可直接触发 PWM Trip Zone。

## 5. SFP 的两种做法

选型前需要先确定 SFP 的用途。

| 做法 | 含义 | 对主控的要求 |
| --- | --- | --- |
| 片内收发器直驱 | Aurora 或 1000BASE-X，用于波形上传 | 需要 GTP / GTX。Artix-7 35T、Zynq-7010、Zynq-7020 均无收发器 |
| 调试数据走光纤 | 串口或百兆以太网外加光电转换 | C2000 可以完成，不必为光口增加 FPGA |

## 6. 五种方案对比

| 维度 | FPGA A7 | Zynq-7 | DSP（C2000） | ARM + FPGA | DSP + FPGA |
| --- | --- | --- | --- | --- | --- |
| 建议器件 | XC7A100T-2FGG484（有 GTP）。A35T 无收发器，不适合 SFP | XC7Z030（4 路 GTX）。7010/7020 无 GTX | F28388D；只做控制算法时用 F28379D | STM32H743 + XC7A100T | F28379D/F28388D + XC7A50T/100T（带 GTP 的封装） |
| AMC3306 | 在可编程逻辑中实现 Sinc3，通道数可扩展，延迟能与 PWM 对齐 | 同 A7，滤波器放在 PL | 硬件 SDFM，比较器直接封波 | 滤波器放在 FPGA，ARM 只读取结果 | 优先使用 DSP 的 SDFM，FPGA 仅作扩展 |
| 六路 PWM | 载波、死区、封波都容易实现。100 kHz 以上分辨率一般为数 ns | PWM 放在 PL | HRPWM 约 150 ps，适合 SiC/GaN 高频；6 路占用很少 | PWM 放在 FPGA。ARM 定时器不足以做逐周封波 | PWM 由 DSP 产生 |
| PFC 与双向切换 | 电流环用 HDL 或 HLS，调整 PI、前馈和模式切换的周期长 | 快环放 PL，电压环和状态机放 Cortex-A9 裸机。A9 存在缓存抖动，50 kHz 电流环不宜只放在 PS | CLA 可并行执行电流环，配套电源控制库含 PFC 与 PLL 参考 | 快环在 FPGA，慢环在 ARM，需维护两套工程 | 环路全部在 DSP，时序最可预期 |
| 锁相与防孤岛 | 算法迭代成本高，适合控制律定型后再固化 | PS 执行 SOGI-PLL 和孤岛策略，PL 执行硬件跳闸 | 电网同步和孤岛判据均有成熟例程 | ARM 执行算法，FPGA 执行跳闸出口 | DSP 执行算法 |
| 保护延迟 | 组合逻辑，可到一个时钟周期 | 同 A7 | SDFM 比较器经 X-BAR 到 Trip Zone，约在 1 µs 以内 | 取决于 FPGA；ARM 中断来不及逐周保护 | DSP 封波；跨芯片故障用硬线，不经过总线 |
| SFP | A50T/A75T/A100T 的 GTP 可直驱光模块 | 仅 7015、7030 及以上有 GTX | 无 SerDes。F28388D 有 MII/RMII，光口需外加 PHY 或光电转换 | 由 FPGA 完成 | 由 FPGA 完成 |
| 串口 / JTAG | MicroBlaze 实现串口；JTAG 适合调试逻辑，不适合反复调整控制算法 | PS 自带 UART，JTAG 可同时观察 ARM 与 PL | UART 满足调试；CCS + XDS 适合电源控制开发 | SWD 与 FPGA JTAG 两套调试器 | 两套调试器 |
| 开发周期 | 最长。锁相、防孤岛和状态机都用硬件描述 | 中等偏长。需要同时完成裸机与 HDL，并划清 PS/PL 边界 | 最短，与电源控制开发方式一致 | 较长。时钟、采样同步和版本配套都要自行规定 | 最长，控制风险最低 |
| 单板复杂度 | 单芯片；仍需外部 ADC、配置 Flash 和上电时序 | 单芯片；通常需要 DDR，电源和 PCB 更重 | 单芯片，模拟与 SDFM 外围最简 | 两芯片，外加并行总线或 SPI | 两芯片，外加互连 |
| 适用情况 | 团队以 FPGA 为主，且控制律已经定型 | 必须单芯片，且 SFP 使用片内收发器 | 控制性能和开发效率优先；SFP 允许外置光电转换 | 必须沿用已有 ARM 软件，FPGA 只做采样和封波 | 控制沿用 C2000，同时需要 Aurora 或千兆光口传波形 |

## 7. 分场景建议

### 7.1 默认方案：TMS320F28388D

- 母线电压和三路电流的 AMC3306 进入 SDFM。
- AMC3306 时钟由 ePWM 时基分频得到，与载波对齐。
- 电网电压用片内 ADC 采样并完成锁相。
- 六路 HRPWM 覆盖双向桥臂和制动斩波。
- 过流、母线过压通过 SDFM 比较器或模拟比较器直接封锁 PWM。
- 防孤岛（电压/频率窗口和主动频率偏移）放在 CPU。
- 串口用于调参，JTAG 使用 XDS。
- SFP 若只承担调试数据出口，使用 F28388D 以太网口加光电转换模块。

不需要片内以太网时，可降为 TMS320F28379D，控制侧能力与 F28388D 同级。

### 7.2 片内 SerDes 直连 SFP：XC7Z030

- PL 负责 AMC3306 抽取、6 路 PWM、死区、逐周封波和 SFP。
- 一颗 Cortex-A9 以裸机方式运行电流环、电压环、SOGI-PLL 和防孤岛。
- 另一颗 Cortex-A9 预留给日志或通信。
- 电流环高于 50 kHz 且 PS 抖动无法接受时，把 PI 和调制移入 PL，A9 保留状态机和防孤岛。
- 不使用 Zynq-7020 替代，该器件没有 GTX。

### 7.3 已有 C2000 算法且需要高速光口：F28379D + XC7A100T

- DSP 独占 SDFM、HRPWM、锁相和防孤岛。
- FPGA 只负责 SFP 和波形搬运。
- 封波信号从 DSP 的 Trip 输出用硬线送到 FPGA，不经过 SPI。
- 没有高速光口需求时，不增加 FPGA。

### 7.4 不作为当前首选的两种做法

- 纯 Artix-7 的时序能力足够，但 PFC 与防孤岛策略仍在迭代时，硬件描述的修改成本高。
- 分立 ARM + FPGA 相对 Zynq 增加一次采样同步，并需要两套调试器。仅在必须复用已有 STM32 软件时采用。

## 8. 原理图约束

1. AMC3306 的 CLK 由主控发出，并与 PWM 时基同源。4 路调制器可共用同一时钟。
2. 锁相使用低延迟 SAR ADC 采集电网电压。AMC3306 用于母线电压和电流；Sinc 延迟在电流环中补偿。
3. 制动斩波和过流封波走组合逻辑或 Trip Zone，不经过通信任务。
4. 防孤岛跳闸与 PWM 硬件故障共用封波路径，软件停住时仍能退出并网。
