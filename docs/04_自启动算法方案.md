# 1000 rpm 表贴式 PMSM 自启动算法方案（25 kHz FPGA FOC）

> 前提：PMSM 旋转电机（表贴式 SPM），目标转速 1000 r/min；控制结构为
> **FPGA 25 kHz 载波 FOC**（接收"电角度 + 电流幅值"并转换为三相电流），
> DSP 以 5 kHz 运行无感观测器/转速环/起动状态机。
> 配套仿真已验证：切换 1.10 s、切换后角度 RMS 1.73°、终值 1000 rpm、24/24 起动成功
> （`sim/`，参数见 §6）。

---

## 0. 结论摘要

| 项目 | 结论 |
|---|---|
| 起动流程 | 预定位(含抖动) → I/f 强拖 2→15 Hz 电 → 观测器确认 → 角度/幅值无扰切换 → 闭环升速至 1000 rpm |
| 切换点 | 15 Hz 电频率 = 225 rpm（目标转速的 22.5%），反电动势 ≈ 10 V，观测器信噪比足够 |
| 接口约定 | DSP 5 kHz 下发 **电流矢量角 θ_v + 电流幅值 I + 每触发周期角度增量 ω_tx**；FPGA 25 kHz 外推角度并生成三相电流 |
| 总启动时间 | ≈ 2.7 s（定位 0.4 + 强拖 0.7 + 确认 0.05 + 淡入 0.1 + 升速 1.5） |
| 低速边界 | 最低可控 ≈ 150 rpm（10 Hz 电）；低于此用 I/f 覆盖，SPM 无零速闭环 |
| 已验证 | 仿真：切换后角度 RMS 1.73°、超调 <1%、蒙特卡洛 24/24 |

## 1. 系统架构与接口约定

```
                 ┌────────────── DSP @5kHz（观测器+转速环+状态机）──────────────┐
 目标转速/自启命令 │  EEMF观测器+PLL → θ̂,ω̂                                        │
                 │  转速PI → iq*     起动状态机 →  θ_v, I, ω_tx, mode             │
                 └──────────────┬────────────────────────────────────────────────┘
                                │ SFP 5kHz 帧（每 5 个载波周期同步一次）
                 ┌──────────────▼────── FPGA @25kHz 载波 FOC ────────────────────┐
                 │ 帧解析 → 角度外推 θ_fpga(t)=θ_rx+ω_tx·(t−t_rx)  （已有模块）     │
                 │ ia*=I·cos θ_fpga, ib*=I·cos(θ_fpga−2π/3), ic*=I·cos(θ_fpga+2π/3)│
                 │ 电流环 PI → SVPWM → 三相逆变器 → PMSM                            │
                 │ 回传：iα/iβ、vα/vβ（200µs 同步平均）、vdc、故障字                │
                 └────────────────────────────────────────────────────────────────┘
```

### 1.1 电流矢量角约定（本方案的核心）

DSP 下发的 θ_v 是**电流矢量的电角度**，FPGA 按 `ia = I·cos θ_v` 生成三相电流：

| 阶段 | θ_v | I | 含义 |
|---|---|---|---|
| 预定位 | 固定角（0=α轴） | I_align | 电流钉在 d 轴，把转子拉到已知位置 |
| I/f | θ_f（强制角，斜坡） | I_f | 电流在虚拟 d 轴，转子以负载角 δ 跟随 |
| 闭环 | **θ̂ + 90°** | i_q*（转速环） | id=0 控制，电流在 q 轴 |

### 1.2 帧格式（5 kHz，与 `docs/02` 一致扩展）

| 方向 | 字段 |
|---|---|
| DSP→FPGA | mode[3b]、θ_v(32b, 0~8191/周)、I(32b, Q0.8 A 峰值)、ω_tx(32b)、enable、清故障 |
| FPGA→DSP | iα/iβ、vα/vβ（200 µs 平均）、vdc、故障字、序号 |

### 1.3 ω_tx 的单位（必须钉死，否则外推错误）

FPGA 外推公式为 `θ(t) = θ_rx + (ω_tx × n) >> 8`（n = 触发周期数 1~4）。因此：

$$
\omega_{tx} = \frac{\Delta\theta_{LSB}}{\text{25 kHz 周期}}\times 256
= \frac{f_e\times8192}{25000}\times256
$$

- 1000 rpm / p=4 → f_e=66.7 Hz → Δθ=21.85 LSB/触发 → **ω_tx = 5595**；
- DSP 侧换算：`ω_tx = round(ω̂_e × 8192/2π / 25000 × 256)`；
- ⚠️ 现有 `fpga/rtl/angle_extrapolator.v` 的 ω 输入注释范围为 0~5120（20×256），
  **1000 rpm 需求已超出**（5595）。合并前把该模块 ω 输入范围放宽到 0~16384
  （无符号 32 位，乘法 `ω×n` 位宽随之加大，或在 DSP 侧按比例缩小），否则高速段外推饱和。

## 2. 起动状态机

```
INIT ─自检OK─► ALIGN ─0.4s─► IF ─f_f≥15Hz─► SETTLE ─确认10拍─► BLEND ─0.1s─► CLOSED ─► 1000rpm
  │              │             │                │               │             │
  └─故障◄────────┴─────────────┴────────────────┴───────────────┴─失步/反转──┘
```

| 状态 | 输出（DSP 每 5 kHz 下发） | 时长 | 退出条件 |
|---|---|---|---|
| INIT | mode=封波，FPGA 自检 | — | 母线/零偏/链路心跳 OK |
| ALIGN | θ_v=θ_align+抖动，I: 0→I_align 斜坡 | 0.4 s | 到时 |
| IF | θ_f 按 f_f 斜坡 2→15 Hz 积分，I=I_f | 0.7 s | f_f≥15 Hz |
| SETTLE | 维持 I/f，观测器并行运行 | ≤0.8 s | 连续 10 拍满足判据；超时升频 100 rpm 重试 |
| BLEND | 角度/幅值交叉淡入（§4） | 0.1 s | 完成 |
| CLOSED | θ_v=θ̂+90°，I=i_q*；转速斜坡 225→1000 rpm | 1.5 s | 失步/反转→FAULT |

## 3. 各阶段设计

### 3.1 预定位（ALIGN）

- `θ_v = θ_align`（取 0，与 α 轴对齐），`I` 以 0.15 s 斜坡升到 **I_align = 15 A 峰值**
  （0.6 倍额定 25 A），再保持 0.25 s；
- **必须叠加抖动**：θ_v = θ_align + A_d·sin(2π·5·t)，A_d ≈ 0.05 rad（≈400 LSB），
  仅前 0.2 s。原因：转子初始角恰为 180° 时对齐转矩为零（不稳定平衡），I/f 会反向
  飞车——仿真复现过（无抖动 92% 成功率），加 5 Hz 抖动后 100%。

### 3.2 I/f 强拖（IF）

- 电频率斜坡：2 → 15 Hz（18.6 Hz/s），θ_f(k+1) = θ_f(k) + f_f·Ts·8192；
- `I_f = 10 A 峰值`（0.4 倍额定）。稳定性条件：

$$
\sin\delta=\frac{T_L+J\dot\omega}{1.5\,p\,\psi_f\,I_f}\le0.85
$$

  本例 p=4、ψf=0.105 → 最大转矩 6.3 N·m，加速+风机负载需求 <1 N·m，裕量 ≥6 倍；
- 失步监视：|ω̂| < 0.5·ω_f 持续 50 ms 或 |i| 突增 1.5 倍 → FAULT。

### 3.3 切换判据（SETTLE）

连续 10 拍（2 ms）同时满足：

1. `|ê| ≥ 6 V`（15 Hz 时理论值 ≈9.9 V）；
2. `|wrap(θ_f − θ̂)| ≤ 25°`；
3. `ω̂ ≥ 0.8·ω_f`。

超时 0.8 s：保持 I/f 继续升频 100 rpm 再确认；连续 2 次失败 → FAULT 后重试。

### 3.4 无扰切换（BLEND）——角度与幅值同步交叉淡入

记负载角 `δ = wrap(θ_f − θ̂)`，切换瞬间 I/f 的转子系分量为
`i_d = I_f·cosδ、i_q = I_f·sinδ`。以 `i_q0 = I_f·sinδ` 预置转速环积分器，
α: 0→1（100 ms）：

$$
\theta_v(\alpha)=\hat\theta+\big[(1-\alpha)\,\delta+\alpha\cdot90^\circ\big],
\qquad I(\alpha)=(1-\alpha)\,I_f+\alpha\cdot i_{q0}
$$

- α=0：θ_v=θ_f、I=I_f（与 IF 完全连续）；
- α=1：θ_v=θ̂+90°、I=i_q0（q 轴电流 = I/f 期间的转矩电流，无阶跃）；
- 全程 q 轴电流分量 I·sin(θ_v−θ̂) 平滑过渡 → 转矩连续、转速无跌落。

### 3.5 闭环升速（CLOSED）

- `θ_v = θ̂ + 90°`；`I = |i_q*|`（负值则 θ_v 取 θ̂−90°，风机工况通常恒正）；
- 转速环：PI（Kp=2.5、Ki=120），输出限幅 ±25 A；
- 转速给定斜坡：225 → 1000 rpm，1.5 s（α=54 rad/s²，转矩需求 ≈2 N·m，远小于限幅）；
- 全程运行失步/反转检测（§5）。

## 5. 保护与重试

| 保护 | 判据 | 动作 |
|---|---|---|
| 相过流 | 32 A 峰值（FPGA 硬件比较器） | 逐周期封波 |
| 失步 | \|ω̂−ω_ref\|>30% 且 \|ê\| 骤降 | FAULT |
| 反转 | ω̂ < −5% 额定持续 20 ms | 立即封波 |
| 堵转 | I≥限值且 ω̂<5% 持续 1 s | FAULT |
| 通信丢失 | FPGA 600 µs 无有效帧 | 自主封波 |
| 重试 | 故障后 2 s | 自动重试 ≤3 次，再失败停机上报 |

## 7. 板级验证（简要）

1. 堵转对齐试验：任意初始角 20 次，定位后转子都到 θ_align；
2. I/f 拖动 0→225 rpm：电流平稳，观测器 |ê| 随速上升；
3. 切换空载 50 次：成功率 100%，iq 波动 <10%、转速跌落 <3%；
4. 带载（50% 风机转矩）50 次：≥98%；
5. 全流程 0→1000 rpm：总启动 <3 s、超调 <5%、稳态误差 <0.5%；
6. 故障注入：反转、失步、丢帧、过流，逐项验证。
