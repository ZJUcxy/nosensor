# 无位置传感器控制算法设计方案

> 对象：300 V / 25 A 表贴式（SPM）旋转永磁同步电机，风机/泵类负载
> 平台：DSP C6678（5 kHz 控制中断）+ FPGA 三相驱动板（FOC/电流环已实现）+ SFP 光纤链路
> 版本：V0.1（方案评审稿）　配套仿真：`sim/`　配套代码骨架：`dsp/`

---

## 0. 结论摘要（先看这一段）

| 项目 | 结论 |
|---|---|
| 观测器主方案 | **估计 dq 坐标系扩展反电动势观测器（EEMF）+ 归一化 PLL**，5 kHz 离散实现 |
| 不选传统 SMO 的原因 | 5 kHz、Ls≈1 mH 时滑模增益 k>130 V 导致每拍电流抖振 k·Ts/Ls≈26 A，边界层无法收敛，见 §4.2 |
| 不选 αβ 静止系全阶观测器的原因 | 反电动势状态随转子旋转，离散误差极点随速退化（3000 rpm 时 0.977），高速相位滞后失锁 |
| 起动方案 | 预定位（含 5 Hz 抖动脉冲破 180° 死点）→ I/f 强拖至 30 Hz 电频率（450 rpm）→ 观测器确认 → 角度交叉淡入 + 转矩电流无扰交接 |

| 仿真结果 | 切换后角度误差 RMS 5.7°；转速阶跃超调 0.4%、90% 上升 82 ms；Rs/Ls/ψf ±30%/±15% 失配下角度误差 ≤5.7°；24 组初始角×负载起动成功率 100% |
| 高速边界 | 5 kHz 下 200 Hz 电频率仅 25 点/周期，建议额定点按 3000 rpm/4 对极设计；若需 >4500 rpm，观测器应下移到 FPGA（方案 B，见 §2.3） |

## 1. 需求与边界条件

### 1.1 被控对象

| 参数 | 符号 | 仿真基线值 | 备注 |
|---|---|---|---|
| 极对数 | p | 4 | 3000 rpm → 200 Hz 电频率 |
| 定子电阻 | Rs | 0.18 Ω | 25 ℃，需温度补偿 |
| 定子电感 | Ld=Lq=Ls | 1.0 mH | 表贴式，凸极率≈1 |
| 永磁磁链 | ψf | 0.105 Wb | |
| 直流母线 | Vdc | 300 V | SVPWM 线性区相电压峰值 173 V |
| 额定/峰值电流 | I | 25 / 32 A(峰值) | |
| 转矩常数 | kt=1.5pψf | 0.63 N·m/A | |
| 转动惯量 | J | 0.01 kg·m² | 含风机 |
| 负载 | TL | 1.42e-4·ωm² | 风机/泵类平方转矩 |

> 以上为**仿真示例参数**，仅用于打通算法与代码链路；实机必须先按 §7 完成辨识并替换。
> 初始值来源：铭牌 + 同功率等级样机经验值。

### 1.2 平台约束（决定了算法形态）

1. **控制周期 5 kHz（200 µs）**：速度环、观测器、状态机全部在 DSP 侧；电流环在 FPGA 侧。
2. **FPGA 已实现 FOC + 电流环**：DSP 输出 `id*、iq*、θ`，FPGA 在 PWM 周期内完成电流闭环与 SVPWM。
3. **DSP↔FPGA 经 SFP 光纤**：存在固定延迟 D_link 与抖动，必须做角度超前补偿；链路必须可监测（序号/时间戳/看门狗）。
4. **无编码器、无旋变**：表贴式凸极率≈1，**零速/极低速无有效凸极信号**，不具备零速大转矩能力（本方案的前提）。
5. **风机/泵类负载**：起动静阻转矩小，允许 I/f 强拖起动，不需要零速闭环。

### 1.3 明确不做的事（边界）

- 不做零速/极低速（<5% 额定转速）闭环转矩控制；如需，须增加高频注入（FPGA 侧实现）或改用 IPM 转子，见 §11。
- 不在 DSP 侧做 PWM 级保护；过流/过压的第一道保护必须在 FPGA 内完成（µs 级）。
- 不依赖编码器做任何标定。

## 2. 总体控制架构

### 2.1 分层

```
                 ┌──────────────────────── DSP C6678 (5 kHz) ───────────────────────┐
  转速给定 ──────►│ 速度 PI ──► iq* ─┐                                                │
                 │                  ├─► 模式管理/起动状态机 ──► θ_cmd = θ̂ + ω̂·T_comp │
  上位机/监控 ◄───│ 观测器(EEMF+PLL) ◄─ iαβ, vαβ                                        │
                 └───────────────┬──────────────────────────────────────────────────┘
                                 │ SFP 光纤（5 kHz 帧，双向）
                 ┌───────────────▼──────────────── FPGA 驱动板 (20 kHz) ──────────────┐
                 │ 帧解析 → 角度外推 θ(t)=θ_rx+ω̂·(t-t_rx) → 电流环 PI(dq) → SVPWM     │
                 │ → 三相逆变器(300V/25A) → PMSM；200 µs 同步平均回传 iαβ/vαβ/vdc      │
                 └───────────────────────────────────────────────────────────────────┘
```

### 2.2 各环带宽分配（5 kHz 采样下的硬约束）

| 环 | 位置 | 带宽/转折 | 说明 |
|---|---|---|---|
| 电流环 | FPGA 20 kHz | 400~600 Hz | 已实现，本文不动 |
| 观测器/PLL | DSP 5 kHz | 250 Hz（观测器）/ 30 Hz（PLL） | PLL 带宽必须显著低于观测器带宽，否则观测器相位滞后引起失锁（仿真已验证：PLL 50 Hz 时 2100 rpm 以上失锁） |
| 速度环 | DSP 5 kHz | 30 Hz（Kp=2.5, Ki=120） | 约 1/7 采样频率 |
| 外环/工艺环 | 上位机 | <2 Hz | 风机不需要更快 |

> **设计红线**：任一闭环带宽 ≤ fs/10 = 500 Hz；速度环 ≤ fs/15。

### 2.3 高速扩展方案（方案 B，风险预案）

当目标转速使电频率 f_e > 250 Hz（>3750 rpm @p=4）时，5 kHz 观测器每个电周期不足 20 点，角度分辨率与延迟补偿误差不可接受。此时：

- 把 EEMF 观测器 + PLL 下移到 **FPGA 内以 20 kHz 运行**，DSP 只做速度环/状态机/监控，5 kHz 帧传 `ω*` 与 `i_q*`；
- 或把 DSP 控制中断提高到 10 kHz（需评估 SFP 链路与 CPU 余量，当前预算余量足够，见部署文档）。

## 3. 电机数学模型

### 3.1 αβ 静止系

$$
v_\alpha = R_s i_\alpha + L_s \frac{di_\alpha}{dt} + e_\alpha,\quad
v_\beta = R_s i_\beta + L_s \frac{di_\beta}{dt} + e_\beta
$$

$$
e_\alpha = -\omega_e\psi_f\sin\theta_e,\qquad e_\beta = +\omega_e\psi_f\cos\theta_e
$$

$$
T_e = 1.5\,p\,\psi_f\,(i_\beta\cos\theta_e - i_\alpha\sin\theta_e)
$$

### 3.2 估计 dq 系（观测器实现用）

以观测角 θ̂ 建立旋转坐标系，反电动势在该系下为**直流量**：

$$
v_d = R_s i_d + L_s\frac{di_d}{dt} - \omega L_s i_q + e_d,\qquad
v_q = R_s i_q + L_s\frac{di_q}{dt} + \omega L_s i_d + e_q
$$

$$
e_d = -E\sin(\theta_e-\hat\theta_e),\qquad e_q = E\cos(\theta_e-\hat\theta_e),\qquad E=\omega_e\psi_f
$$

**关键点**：只要 θ̂≈θe，e_d≈0，e_q≈E。角度误差直接反映在 e_d 上，这是 PLL 的鉴相依据，也是本方案优于 αβ 系观测器的根本原因。

## 4. 观测器：选型、推导与整定

### 4.1 候选方案对比

| 方案 | 零速 | SPM 适用 | 5 kHz 可行性 | 参数敏感 | 实现量 | 结论 |
|---|---|---|---|---|---|---|
| 传统 SMO（sign/sat + LPF） | 否 | 是 | **差**：抖振 k·Ts/Ls 过大 | 中 | 小 | 备选，需 ≥10 kHz |
| αβ 系全阶观测器 | 否 | 是 | 中：极点随速退化 | 中 | 中 | 不采用（仿真失锁） |
| **估计 dq 系 EEMF 观测器** | 否 | 是 | **好**：定常线性系统 | 低-中 | 中 | **主方案** |
| 电压模型磁链 + 漂移补偿 | 否 | 是 | 好 | 高（Rs/偏置积分漂移） | 小 | 交叉校验用 |
| MRAS（电流误差） | 否 | 是 | 中 | 中 | 中 | 备选 |
| 高频注入（饱和凸极） | 是 | 弱 | 需 FPGA 侧 | 高 | 大 | 二期可选 |
| EKF | 否 | 是 | 差（5 kHz 下协方差整定困难） | 中 | 大 | 研究项 |

### 4.2 为什么排除传统 SMO（量化理由）

滑模观测器要求增益 k 大于反电动势峰值才能维持滑动模态。3000 rpm 时 E=132 V，取 k=150 V。每个采样周期滑模项造成的电流跳变：

$$
\Delta i = \frac{k\,T_s}{L_s} = \frac{150\times200\times10^{-6}}{1\times10^{-3}} = 30\ \text{A}
$$

而合理边界层 φ 仅 5~10 A，滑模面在每个采样周期内被"穿透"，等效控制量出现大幅抖振，5 kHz 下低通滤波器无法在 200 Hz 电频率与 5 kHz 开关纹波之间取得可用折中。**结论：5 kHz 平台不适合传统 SMO，除非观测器下移到 FPGA（20 kHz 时 Δi=7.5 A，仍偏大，需配合宽边界层）。**

### 4.3 主方案：估计 dq 系 EEMF 观测器

**观测器方程**（DSP 以 Ts=200 µs 离散执行；Park 变换使用上一拍 θ̂）：

$$
\begin{aligned}
\dot{\hat i}_d &= \frac{v_d - R_s\hat i_d + \omega L_s\hat i_q - \hat e_d}{L_s} + L_1(i_d-\hat i_d)\\
\dot{\hat i}_q &= \frac{v_q - R_s\hat i_q - \omega L_s\hat i_d - \hat e_q}{L_s} + L_1(i_q-\hat i_q)\\
\dot{\hat e}_d &= L_2(i_d-\hat i_d),\qquad \dot{\hat e}_q = L_2(i_q-\hat i_q)
\end{aligned}
$$

**增益整定（解析式）**：误差特征方程

$$
s^2+\left(\frac{R_s}{L_s}+L_1\right)s-\frac{L_2}{L_s}=0
\;\Rightarrow\;
L_1=2\omega_o-\frac{R_s}{L_s},\quad L_2=-L_s\omega_o^2
$$

取 ωo=2π·250 rad/s → L1=1549、L2=-2467（Rs=0.18, Ls=1 mH）。
> 注意 L2 为**负**：电流估计偏小意味着反电动势估计偏大，必须反向修正。符号写反会直接发散（调试中最常见的坑）。

**离散实现**：电流用前向欧拉（ωo·Ts=0.31，稳定）；反电动势用前向欧拉积分。若 Ls 很小（<0.3 mH）导致 ωo·Ts 过大，改用精确 ZOH 离散（`a=exp(-RsTs/Ls)`）。

### 4.4 锁相环（PLL）

鉴相：`ε = -ê_d / |ê|`（小角度下 ε≈sin(θe-θ̂e)）。
环路：`ω̂ = Kp·ε + Ki∫ε`，`θ̂ = ∫ω̂`，`Kp=2ζωn, Ki=ωn²`，取 ωn=2π·30、ζ=1。

**整定约束**：
- ωn ≤ ωo/5（否则观测器相位滞后进入环路，高速失锁——仿真中 PLL 50 Hz + 观测器 250 Hz 在 2100 rpm 失锁，降到 30 Hz 后全速域稳定）；
- 反电动势幅值低于门限（本方案 4 V）时**冻结 PLL 并缓慢复位频率积分**，避免不可观测区（预定位/I/f 初期）随机游走，见 §6.4。

### 4.5 角度超前补偿

DSP 发出的角度在应用于电机前存在三段延迟：SFP 传输 D_link、FPGA 流水线、PWM 半周期。补偿方式：

$$
\theta_{cmd}=\hat\theta+\hat\omega\cdot T_{comp},\qquad
T_{comp}\approx D_{link}+T_{s}/2+T_{pwm}/2
$$

- 仿真基线 D_link=100 µs、Ts=200 µs → T_comp 理论值 ≈ 200 µs；
- 但观测器在计算中已把反电动势外推一拍（等效 +200 µs），实测最优 T_comp 落在 **0~200 µs**，必须台架标定（方法见验证文档 §5.4：固定转速扫描 T_comp，取 |id| 最小点）；
- 补偿误差的代价：T_comp 偏 150 µs 在 3000 rpm 下造成约 6° 失配、约 3 A 的 d 轴电流浪费。

### 4.6 低速性能边界

| 转速 | 电频率 | 反电动势 | 观测器角度误差（仿真） | 可用性 |
|---|---|---|---|---|
| 450 rpm (10%) | 30 Hz | 20 V | <2° | 切换点，可用 |
| 900 rpm (30%) | 60 Hz | 40 V | ~2° | 可用 |
| 1500 rpm (50%) | 100 Hz | 66 V | ~3.6° | 可用 |
| 3000 rpm (100%) | 200 Hz | 132 V | ~7°（含延迟，可补偿） | 可用 |

低于 10% 转速观测器信噪比不足，**由 I/f 覆盖**，这是本方案速域划分的依据。

## 5. 电流/转矩指令生成

- SPM 无磁阻转矩，额定速域内 **id*=0**（不弱磁）；
- 电压极限校验：`|v| = sqrt((ωL iq + Rs id)^2 + (ωψf + Rs iq - ωL id)^2) ≤ Vdc/√3`；
  若超限则按电压椭圆限幅 iq*，并置"电压受限"标志（本机型 3000 rpm 时裕量约 20%，正常工况不触发）；
- 转矩/电流限幅：`iq* ∈ [-25, +25] A`，硬件过流 32 A 由 FPGA 独立保护；
- 速度环输出即 iq*，带条件积分抗饱和（饱和时停止同向积分）。

## 6. 起动算法（重点）

### 6.1 状态机

```
INIT ──自检OK──► ALIGN ──0.35s──► IF ──we≥30Hz──► SETTLE ──确认N拍──► BLEND ──0.1s──► CLOSED
  │                │                │                 │                  │              │
  └─故障─► FAULT ◄─┴────────────────┴─────────────────┴──────────────────┴──失步/超差──┘
```

| 状态 | 输出 | 时长 | 进入条件 | 退出条件 |
|---|---|---|---|---|
| INIT | 封波 | — | 上电/复位 | 自检通过（母线、电流零偏、链路心跳） |
| ALIGN | id*=15 A 斜坡，iq*=±2 A@5 Hz 抖动 | 0.35 s | 自检通过 | 到时 |
| IF | id*=10 A（虚拟 d 轴），角度按 ωf 斜坡 2→30 Hz | 0.9 s | 定位结束 | ωf≥30 Hz |
| SETTLE | 维持 I/f，观测器并行运行 | ≤0.8 s | 到达切换频率 | 连续 10 拍满足切换判据；超时则降级/重试 |
| BLEND | 角度交叉淡入 + 转矩电流交接 | 0.1 s | 判据满足 | 淡入完成 |
| CLOSED | 速度环 + 观测角 | — | 淡入完成 | 失步/超差/故障 |

### 6.2 预定位（ALIGN）

- 电流幅值 15 A（约 60% 额定），0.15 s 斜坡上升，再保持 0.2 s；
- **必须加抖动脉冲**：`iq* = 2·sin(2π·5·t)` 持续 0.2 s。原因：转子恰在 180°（与定位磁场反向）时为不稳定平衡，纯 d 轴电流产生零转矩，I/f 起动会反向飞车（仿真复现：初始角 180° 时反转至 -1780 rpm）。5 Hz 抖动给转子一个确定方向的扰动，使其必然落到 0°，24 组初始角起动成功率由 92% 提升到 100%；
- 大惯量或带载工况可改为"两步定位"（0° 保持 → 转 90° 保持），用电流响应判断是否堵转（本方案风机负载不需要）。

### 6.3 I/f 强拖

虚拟 d 轴电流 `id_if = I_f`，`iq_if = 0`，角度 `θf` 按斜坡频率积分。

**稳定性判据**（负载角）：

$$
\sin\delta = \frac{T_L(\omega)+J\dot\omega}{1.5\,p\,\psi_f\,I_f}\;\le\;\sin\delta_{max}\approx0.85
$$

风机负载轻，取 I_f=10 A（最大转矩 6.3 N·m）即可覆盖 0→450 rpm 的加速与阻转矩；
升速速率由 `J·dω/dt + TL ≤ 1.5pψf·I_f·sinδ_max` 反解，本方案 0→30 Hz 用 0.9 s（约 33 Hz/s 电），留有 2 倍裕量。

**失步检测**（IF 期间）：若 `|ω̂| < 0.5·ωf` 持续 50 ms，或电流幅值突增 >1.5 倍给定，判失步 → FAULT，等待 2 s 后重试（最多 3 次）。

### 6.4 观测器确认与切换判据（SETTLE）

同时满足、连续 10 拍（2 ms）：

1. `|ê| ≥ 10 V`（反电动势可信）；
2. `|wrap(θf - θ̂)| ≤ 25°`（观测角与强制角一致，说明负载角小、观测已收敛）；
3. `ω̂ ≥ 0.8·ωf`（速度估计跟得上）。

超时 0.8 s 未满足 → 判定观测器未收敛，保持 I/f 继续升速 100 rpm 后重试；连续两次失败 → FAULT。

### 6.5 无扰切换（BLEND）——本方案的核心细节

直接切角会造成转矩冲击（iq 阶跃），必须**角度交叉淡入 + 转矩电流交接**同时做：

**角度**（在圆周上按最短路径混合）：

$$
\theta_{cmd}=\hat\theta+(1-\alpha)\cdot\mathrm{wrap}(\theta_f-\hat\theta),\qquad \alpha:0\to1\ \text{线性}, T_{blend}=100\ \text{ms}
$$

**电流交接**：切换瞬间 I/f 电流矢量在估计转子系中的分量为
`id = I_f·cos δ̂, iq = I_f·sin δ̂`（δ̂ = θf - θ̂）。
以 `iq_init = I_f·sin δ̂` 预置速度环积分器，并把速度给定设为当前 `ω̂/p`，实现 **iq* 连续、无阶跃**；随后 0→100 ms 内 id* 由 `I_f·cosδ̂` 斜坡到 0。

**验收**：切换过程 iq 波动 <10%、转速跌落 <3%、无反向转矩。仿真结果：切换瞬间 iq 无阶跃，转速平滑过渡（见 `S1_transition_zoom.png`）。

### 6.6 运行中失步/反转保护

- 反转检测：`ω̂ < -5% ω_rated` 持续 20 ms → 立即封波（防飞车）；
- 失步检测：`|ω̂ - ω_ref| > 30%` 且 `|ê|` 骤降 30% → 切回 I/f 或 FAULT；
- 观测器可信度看门狗：连续 20 拍 `|ê|` 与 `ω̂·ψf` 偏差 >40% → 视为观测失效。

## 7. 参数辨识（只有铭牌时的必做项）

| 参数 | 方法 | 激励 | 计算 | 精度目标 |
|---|---|---|---|---|
| Rs | 堵转直流注入 | 两相串联通 5 A DC，测线电压 | Rs=U/(2I)，记录温度 | ±3% |
| Ls | 堵转交流注入 | 1 kHz 小信号，测电压/电流相位 | Ls=sqrt((U/I)²-Rs²)/ω | ±5% |
| ψf | 空载拖动/对拖 | I/f 拖到 500~1000 rpm，测线电压基波 | ψf=√2·U_ll,rms/(√3·ωe) | ±3% |
| J | 自由停机 | 3000 rpm 断电，记录 n(t) 曲线 | J=TL/(dω/dt)，TL 用已知阻转矩 | ±10% |
| 电流零偏 | 上电自校准 | 封波，采 200 ms 平均 | 偏置 = 均值 | ±0.05 A |
| 死区电压 | 堵转低压扫描 | 0.5~5 A 多点 | 由电压-电流非线性拟合 | ±1 V |
| 逆变器压降 | 同上 | 同上 | Vce + R_igbt·I | — |

**辨识顺序**：零偏 → 死区 → Rs → Ls → ψf → J。每项试验都要限流、限时、限温，试验前确认散热与急停。

## 10. 与现有 FPGA 固件的接口约定（详见部署文档）

DSP 每 5 kHz 下发：`id*、iq*、θ_cmd、ω̂、使能、模式、复位`；
FPGA 每 5 kHz 回传：`iα、iβ、vα、vβ、vdc、温度、故障字、序号、时间戳`。
**关键要求**：回传的 vα/vβ 必须是**实际施加电压的 200 µs 同步平均值**（含死区影响），否则观测器模型失配，低速角度误差显著变大。

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 180° 定位死点 | 起动反转飞车 | 抖动脉冲；反转检测 20 ms 封波 |
| 5 kHz 高速角度分辨率不足 | >3750 rpm 失锁 | 方案 B：观测器下移 FPGA / 提高中断频率 |
| T_comp 标定错误 | id 浪费、转矩下降 | 台架按 |id| 最小标定；运行时监控 id 偏置 |
| 电流零偏/死区 | 观测器低速误差、转矩脉动 | 上电自校准；FPGA 死区补偿 |
| Rs 温漂（0.4%/℃） | 低速角度误差 | Rs 温度模型或在线辨识（d 轴稳态电压法） |
| 风机惯量大、起动慢 | I/f 时间过长、发热 | 按 §6.3 反解升速率；必要时提高 I_f |
| SFP 丢帧/抖动 | 角度跳变 | 序号+CRC+看门狗；连续丢 3 帧 FPGA 自主封波 |
| 负载突变（风道堵塞） | 失步 | 失步检测 + 回退 I/f |

## 12. 待确认输入（影响后续细化）

1. 电机铭牌完整数据（额定功率/转速/电流/反电势/极对数）——用于替换仿真参数；
2. 风机负载曲线（额定点转矩、起动阻转矩）——决定 I_f 与升速率；
3. 最高转速要求——决定是否需要方案 B；
4. SFP 链路实测延迟与抖动——决定 T_comp 与帧周期余量；
5. 驱动板电流采样方式（分流/霍尔）、ADC 位数与零偏稳定性——决定低速下限。
