# 仿真与板级验证计划

> 目标：用**仿真→代码回放→台架→整机**四级验证，把 `docs/01` 的算法在现有硬件上做成可复现的 demo。
> 原则：每一级都有明确的**通过判据**与**失败回退动作**，不允许"先上电再说"。

---

## 1. 验证分级

```
L0 模型仿真(Python/MATLAB)  ──►  L1 代码一致性(C 回放 golden)  ──►  L2 台架空载  ──►  L3 台架带载  ──►  L4 连续运行/环境
      sim/                         dsp/test                       电机+驱动器        测功机/风机        温升/振动/EMC
```

| 级别 | 目的 | 不通过时 |
|---|---|---|
| L0 | 算法可行性、参数敏感性、边界条件 | 改算法/改参数，回到设计 |
| L1 | 保证 DSP 里的 C 代码与仿真模型一致 | 修代码，不允许"台架上再调" |
| L2 | 链路、采样、角度定义、保护正确 | 停在 L2，禁止带载 |
| L3 | 起动、切换、全速域、动态性能 | 回 L0/L1 定位 |
| L4 | 工程可用性 | 降额或改方案 |

## 3. L1 代码一致性验证（PIL）

目的：证明 DSP 里的 C 实现与 Python 参考模型**逐比特一致**（浮点允许 1e-6 相对误差）。

1. 仿真导出 `sim/results/golden_vectors.csv`（输入 iα/iβ/vα/vβ，输出 θ̂/ω̂/|ê|）；
2. `dsp/test/test_sensorless.c` 逐行回放，输出 `out.csv`；
3. 用 `sim/compare_golden.py` 比对，误差 >1e-5 判失败；
4. 通过后，C 代码冻结版本号，台架只允许调参数（Kp/Ki/T_comp），不允许改结构。

> 若暂时没有 PC 端 C 编译器，可在 CCS 里建 host 工程，或用 MATLAB MEX 编译同一份 C 源码回放。

## 4. 台架配置

### 4.1 设备清单

| 设备 | 规格 | 用途 |
|---|---|---|
| 直流电源 | 0~400 V / 0~30 A，可编程 | 母线供电，限流保护 |
| 被测驱动板 | 现有 FPGA 三相板 | 300 V/25 A |
| DSP 控制板 | C6678 | 5 kHz 控制 |
| 被测电机 | 300 V/25 A SPM | 表贴式 |
| 负载 | 风机或测功机（0~20 N·m，0~3000 rpm） | 加载 |
| 示波器 | ≥4 通道，100 MHz，带电流探头 | 相电流/电压/GPIO 打点 |
| 功率分析仪 | 可选 | 效率/谐波 |
| 温度记录 | 热电偶/PT100 | 电机绕组、IGBT |
| 安全 | 急停、泄放电阻、隔离栅、防护罩 | 强制 |

### 4.2 安全前置条件

- 母线电容必须带泄放电阻（断电 5 s 内 <60 V）；
- 调试初期串接 5 A 限流与快速熔断；
- 电机与负载必须机械固定、加防护罩；
- 所有上电试验双人确认，急停随手可及。
