# 硬件部署与 SFP 接口方案

> 目标：把 `docs/01` 的算法落到 C6678 + FPGA 双芯片架构上，明确**谁算什么、怎么传、多久算完、出错怎么办**。
> 适用：现有 DSP C6678 控制板 + FPGA 三相驱动板（FOC/电流环已实现），SFP 光纤 5 kHz 通信。

## 2. DSP 侧部署

### 2.1 核间分工

| 核 | 任务 | 周期 | 负载估计 | 备注 |
|---|---|---|---|---|
| Core0 | 控制 ISR：帧解析→Clarke/Park→观测器→PLL→速度环→FSM→帧打包 | 200 µs | ≈15~25 µs（含中断开销） | 代码/数据放 L2，禁 Cache |
| Core1 | 5 kHz 录波：把 16~32 个通道写入 DDR3 环形缓冲 | 200 µs | <5 µs | 用 EDMA 搬运，双缓冲 |
| Core2 | 上位机协议（TCP/UART）、参数读写、辨识流程 | 10 ms | 低 | 非实时 |
| Core3 | 预留：第二观测器/在线参数辨识 | — | — | 便于 A/B 对比 |
| Core4~7 | 预留 | — | — | HIL/诊断 |

**IPC**：Core0→Core1 用共享内存 + 标志位（不用操作系统信号量，避免不确定性）；参数区用双缓冲（Core2 写影子区，Core0 在周期边界切换）。

### 2.2 5 kHz ISR 时序预算（C6678 @1 GHz，实测需打点确认）

| 步骤 | 估计耗时 | 备注 |
|---|---|---|
| 中断响应 + 现场保护 | 0.3 µs | 关中断窗口全程 <1 µs |
| 帧校验/解析（64 B，CRC32 查表） | 1.2 µs | 或由 EDMA+硬件 CRC 完成 |
| Clarke/Park（sin/cos 查表或 CORDIC） | 0.4 µs | 查表 1024 点 + 线性插值 |
| EEMF 观测器（约 60 次浮点运算 + 4 次三角） | 1.5 µs | 全 float32 |
| PLL + 速度滤波 | 0.4 µs | |
| 速度 PI + 限幅 + 抗饱和 | 0.2 µs | |
| 状态机 + 保护判断 | 0.2 µs | |
| 角度补偿 + 帧打包 + CRC | 1.0 µs | |
| **合计** | **≈5 µs** | 占 200 µs 的 2.5%，余量充足 |

> 即使把观测器跑两遍（A/B 对比）或加入 Rs 在线辨识，仍在 10 µs 以内。**CPU 不是瓶颈，确定性才是**：所有代码/数据放 L2 SRAM（1 MB/核），关闭该段 L1D Cache；中断入口到出口关中断；避免动态内存与浮点除零异常。

### 2.3 定时与同步

- 5 kHz 节拍源：**DSP 定时器为主**（TIMER0 周期中断），FPGA 以收到帧为准启动 200 µs 窗口；
- 若实测帧抖动 >10 µs，改为 **FPGA 载波为主**：FPGA 每 200 µs 发"采样有效"帧，DSP 以帧到达中断触发控制（需评估中断延迟一致性）。
- 抖动验收：GPIO 打点 + 示波器，ISR 抖动 <2 µs，帧周期抖动 <5 µs。

### 2.4 调试与观测

- Core0 每个周期翻转一个 GPIO（PWM 同步），示波器测 ISR 执行时间与抖动；
- Core1 录波通道：`ω_ref, ω̂, θ̂, θ_true(调试用), id, iq, id*, iq*, ê_d, ê_q, |ê|, vdc, mode, fault`；
- 录波深度：5 kHz × 32 通道 × 4 B = 640 kB/s，DDR3 512 MB 可存 13 分钟，足够完整试验；
- 上位机通过以太网按需导出 CSV，直接与仿真结果对比。

## 3. FPGA 侧改造清单（按优先级）

| 优先级 | 改造项 | 原因 | 验收 |
|---|---|---|---|
| P0 | **回传 vα/vβ 的 200 µs 同步平均值** | 观测器需要实际施加电压；用指令值代替会引入死区/饱和误差 | 与示波器实测电压误差 <2% |
| P0 | **角度外推**：`θ(t)=θ_rx+ω̂_rx·(t-t_rx)` | 5 kHz 角度在 20 kHz 上必须插值，否则高速电流畸变 | 3000 rpm 相电流 THD <5% |
| P0 | **通信看门狗**：连续 3 帧丢失 → 封波并置故障位 | DSP 死机/光纤断开时必须由 FPGA 兜底 | 拔纤试验：<1 ms 封波 || P1 | **死区补偿**（符号法 + 过零区线性化） | 低速观测器误差与 6 次谐波 | 5% 额定电流下 5/7 次谐波 <1% |
| P1 | **逐周期过流保护**（硬件比较器 + 封波） | 安全底线 | 32 A 触发，动作 <10 µs |
| P1 | **母线过压/制动斩波** | 风机减速回馈 | 380 V 触发 |
| P2 | 200 µs 窗口时间戳 | 延迟在线测量与补偿 | 时间戳误差 <1 µs |
| P2 | 高频注入通道（预留） | 二期零速方案 | 可下发注入幅值/频率 |

> **角度外推模块已交付**：`fpga/rtl/angle_extrapolator.v`（含自校验 testbench，见 `fpga/README.md`）。
> 接口为 DSP 直接下发 `θ_in/ω_in + 5 kHz sync + 25 kHz trig + dir`，模块在 sync 装载、在随后的
> 4 个触发周期按 `θ = θ_in ± (ω·n)>>8` 外推并自动对 8192 回绕，与上表 P0 要求一致。
>
> 如果 P0/P1 无法改动，则退化方案：DSP 用 `v*` 指令 + vdc 重构电压，观测器低速误差会明显变大（预计角度误差 +5~10°），必须在验收指标上让步。

## 4. SFP 帧格式（建议）

### 4.1 物理层与速率

- 5 kHz × 64 B × 2 = 640 kB/s，链路速率余量极大（百兆级即可）；
- 帧长固定 64 B，便于 FPGA 定长解析与 DMA；
- 建议加 8 B 前导/同步字，接收端按同步字对齐。

### 4.2 DSP → FPGA（命令帧，64 B）

| 偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | magic | u16 | 0xA55A |
| 2 | seq | u16 | 每帧 +1，用于丢帧检测 |
| 4 | mode | u8 | 0=封波 1=预定位 2=I/f 3=闭环 4=故障 |
| 5 | enable | u8 | 0/1 |
| 6 | reset_fault | u8 | 写 1 清故障 |
| 7 | flags | u8 | bit0 制动 bit1 弱磁 bit2 注入使能 |
| 8 | id_ref | f32 | A（峰值） |
| 12 | iq_ref | f32 | A（峰值） |
| 16 | theta_cmd | f32 | rad，已含 T_comp 超前 |
| 20 | omega_est | f32 | rad/s（电角速度），FPGA 外推用 |
| 24 | i_limit | f32 | A，动态限流 |
| 28 | vdc_limit | f32 | V |
| 32 | t_comp | f32 | s，在线微调 |
| 36~56 | reserved | — | 预留（注入幅值/频率等） |
| 56 | crc32 | u32 | 覆盖 0~55 |
| 60 | tail | u32 | 0x5AA5C33C |

### 4.3 FPGA → DSP（反馈帧，64 B）

| 偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | magic | u16 | 0x5AA5 |
| 2 | seq | u16 | 回显或独立计数 |
| 4 | status | u16 | bit0 电流环就绪 bit1 PWM 运行 bit2 电压受限 |
| 6 | fault_code | u16 | 过流/过压/超温/丢帧/硬件故障 |
| 8 | i_alpha | f32 | A，200 µs 平均 |
| 12 | i_beta | f32 | A，200 µs 平均 |
| 16 | v_alpha | f32 | V，实际施加电压 200 µs 平均 |
| 20 | v_beta | f32 | V |
| 24 | vdc | f32 | V |
| 28 | temp_power | f32 | ℃（IGBT/NTC） |
| 32 | temp_motor | f32 | ℃（若有线） |
| 36 | t_stamp | u32 | FPGA 200 µs 计数 |
| 40 | theta_applied | f32 | 本窗口实际使用的角度（调试用） |
| 44~56 | reserved | — | |
| 56 | crc32 | u32 | |
| 60 | tail | u32 | |

### 4.4 链路健壮性

- **序号连续性**：丢帧计数，连续 3 帧 → 故障；误码由 CRC32 检出；
- **超时**：FPGA 若 600 µs 未收到有效帧 → 封波（可配置）；
- **双向心跳**：DSP 侧若 3 拍未收到反馈 → 立即进入安全状态并停发；
- **环回测试模式**：FPGA 把收到的帧原样回传，用于测量链路延迟与误码率（出厂自检必做）。

## 5. 时序与延迟补偿

### 5.1 延迟组成

| 环节 | 典型值 | 测量方法 |
|---|---|---|
| DSP 计算 + 打包 | 5 µs | GPIO 打点 |
| SFP 发送/接收 | 2~5 µs | 环回 |
| FPGA 解析 + 等待 PWM 周期 | 0~50 µs | 时间戳 |
| 电流环计算 + SVPWM 更新 | 25~50 µs | 内部计数器 |
| 采样窗口平均 | 100 µs | 固定（Ts/2） |
| **合计（前向）** | **约 130~210 µs** | 环回 + 打点联合标定 |

### 5.2 补偿策略

`θ_cmd = θ̂ + ω̂·T_comp`，T_comp 为**可标定参数**，初值按 `D_link + Ts/2 + T_pwm/2` 取 200 µs，台架按"固定转速下 |id| 最小"扫描确定（见验证文档 §5.4）。仿真采用 0~200 µs 区间，说明观测器的一拍预测已抵消部分延迟。

### 5.3 高速残余误差预算（3000 rpm，200 Hz 电）

| 误差源 | 角度误差 |
|---|---|
| T_comp 残差 ±50 µs | ±3.6° |
| 观测器相位滞后 | ~3° |
| 电流环跟踪滞后 | ~2° |
| **合计** | **<9°**（对应转矩损失 <1.2%） |

## 6. 保护与安全

| 保护 | 检测位置 | 阈值 | 动作 | 响应时间 |
|---|---|---|---|---|
| 相过流 | FPGA 比较器 | 32 A（峰值） | 封波 + 故障锁存 | <10 µs |
| 母线过压 | FPGA ADC | 380 V | 封波 + 制动斩波 | <100 µs |
| 母线欠压 | FPGA | 200 V | 封波 | <100 µs |
| 超温 | FPGA NTC | 85 ℃（IGBT）/ 130 ℃（电机） | 降额 → 封波 | 1 ms |
| 通信丢失 | FPGA | 600 µs 无帧 | 封波 | 600 µs |
| 反转/失步 | DSP | §6.6 判据 | 封波 + 故障 | 20~50 ms |
| 堵转 | DSP | 电流>限值且 ω̂<5% 持续 1 s | 封波 | 1 s |
| 急停 | 硬件 | 按钮/外部 | 断主接触器 + 泄放 | <10 ms |

**上电/下电顺序**：预充电（限流电阻 50~100 Ω，1~2 s）→ 母线建立 → FPGA 自检 → DSP 自检（零偏校准）→ 允许运行；下电：封波 → 泄放电阻放电至 <60 V → 断接触器。

**安全底线**：DSP 只做"策略级"保护，任何情况下不得取消 FPGA 的硬件保护；调试时必须串接直流电源限流与快速熔断器。

## 7. DSP 软件结构

```
dsp/
├── inc/
│   ├── sensorless.h      # 观测器/PLL/速度环接口与数据结构
│   ├── startup_fsm.h     # 起动状态机
│   └── sfp_proto.h       # 帧结构体（与 §4 一一对应，含静态断言检查长度）
├── src/
│   ├── sensorless.c      # 与 sim/sensorless.py 逐行对应
│   ├── startup_fsm.c
│   ├── control_isr.c     # 5kHz ISR 主流程
│   ├── sfp_proto.c       # 打包/解析/CRC32
│   └── params.c          # 参数表、默认值、CRC 保护
└── test/
    ├── test_sensorless.c # 离线回放 golden_vectors.csv（PC 或 CCS 均可）
    └── README.md
```

**编码规范**：全 float32（C66x 单精度吞吐高，double 慢一个量级）；禁用动态内存；所有状态量显式初始化；角度统一弧度并 wrap 到 [-π,π)；每个周期入口保存 `状态快照` 供故障后分析。

## 8. 板级 bring-up 顺序（与验证文档配合）

1. **静态检查**：母线/驱动/光纤，限流电源 5 A 上电，测各路电源；
2. **链路自检**：FPGA 环回，测误码率与延迟（>1e6 帧 0 误码）；
3. **电流采样标定**：封波，零偏校准，注入已知电流核对增益；
4. **开环电压试验**：小电压 V/f 空载转动，确认相序与角度定义（正转 = θ 递增）；
5. **电流环验证**：堵转下 d/q 阶跃，确认带宽与超调（FPGA 侧，本方案不改）；
6. **参数辨识**：Rs/Ls/ψf/J（§7 of 01）；
7. **I/f 运行**：0→450 rpm，观察电流与观测器；
8. **观测器对比**：录波 θ̂ 与 θf，确认角度差 <25°；
9. **切换试验**：空载 → 50% 负载，各 50 次；
10. **闭环全速域**：500→3000 rpm 阶梯，记录角度误差/电流/温升；
11. **动态试验**：转速阶跃、负载阶跃、断电重投；
12. **保护试验**：过流/过压/丢帧/急停，逐项验证。

## 9. 资源与风险

| 项 | 现状 | 需求 | 风险 |
|---|---|---|---|
| DSP 算力 | C6678 8 核 | <10% 单核 | 无 |
| DSP 内存 | 每核 1 MB L2 | 控制 <64 kB | 无 |
| SFP 带宽 | 百兆级 | 0.64 MB/s | 无 |
| FPGA 逻辑 | 现有 FOC | +角度外推+平均+死区补偿 | 需确认资源余量（LUT/DSP/BRAM） |
| FPGA 采样同步 | 未知 | 200 µs 窗口与帧对齐 | **主要风险**，需先做环回与时戳试验 |
| 光纤延迟一致性 | 未知 | 抖动 <10 µs | 需实测 |
