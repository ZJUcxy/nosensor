# FPGA 模块：电角度外推（angle_extrapolator）

对应 [docs/02 硬件部署与SFP接口方案](../../docs/02_硬件部署与SFP接口方案.md) §3 的 P0 项「角度外推」：
DSP 每 5 kHz 下发一次电角度 θ 与角速度 ω，本模块在两次下发之间按 25 kHz 触发
逐周期外推电角度，消除 5 kHz 角度台阶在高速下造成的电流畸变。

## 1. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | in | 1 | 256 MHz |
| rst_n | in | 1 | 复位，低有效 |
| theta_in | in | 32 | 电角度，0~8192（8192=360°，内部归一为 0） |
| omega_in | in | 32 | 角速度，无符号 Q0.8，0~20·2^8（0~5120） |
| sync | in | 1 | 5 kHz 同步（DSP 帧有效标志），脉冲宽度 ≥3 clk |
| trig | in | 1 | 25 kHz 触发，脉冲宽度 ≥3 clk |
| dir | in | 1 | 方向：1=角度加，0=角度减 |
| theta_out | out | 32 | 计算电角度，0~8191，在 sync/trig 时更新 |

## 2. 行为

```
        ┌──────────── 200 us (5 kHz) ────────────┐
sync    ─┘────────────────────────────────────────┘─
trig    ─┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──  (40 us, 25 kHz)
theta_out: θin  θin+Δ  θin+2Δ  θin+3Δ  θin+4Δ   θin'(重新装载)
             n=0   n=1     n=2     n=3     n=4      n=0
Δ = (ω · n) >> 8，dir=1 为加，dir=0 为减；结果对 8192 取模
```

1. **sync 上升沿**：锁存 `theta_in / omega_in / dir`，`theta_out = theta_in`（8192 归一为 0），
   触发周期计数 `n = 0`。若 sync 与 trig 同拍到达，sync 优先。
2. **sync 之后的每个 trig 上升沿**：`n = n+1`（上限 4），
   `theta_out = theta_in_latched ± (ω_latched·n >> 8)`，按 dir 加减，回绕到 0~8191。
3. 25 kHz = 5×5 kHz：每个同步周期内第 1 个触发与同步对齐（装载），
   之后 **4 个触发各外推一拍（n=1..4）**，即「同步后四个周期外推」。
4. sync 丢失时 n 封顶在 4，角度保持最后外推值不漂移，待下一个 sync 重新装载；
   复位后、首次 sync 之前，trig 被忽略，输出保持 0。

## 3. 计算与位宽

- 乘法：`ω(≤5120, 13bit) × n(4bit) → 17bit`，右移 8 位得增量（Q0.8 → 整数）。
- 单次增量最大 `5120×4>>8 = 80` LSB，远小于 8192，回绕只需一次加减。
- 实现为**单周期组合计算 + 一拍寄存器**，在 256 MHz 下时序余量充足；
  资源约 1 个 32×4 乘法器 + 几十个触发器，无需 DSP 块（LUT 即可）。

## 4. 仿真

```bash
iverilog -o tb.out rtl/angle_extrapolator.v tb/tb_angle_extrapolator.v
vvp tb.out          # 期望最后一行 "SIM PASS"
```

关键验证点（与 testbench 中场景一一对应）：

| 场景 | 输入 | 输出序列 |
|---|---|---|
| 装载+外推 | θ=1000, ω=256, dir=1 | 1000 → 1001 → 1002 → 1003 → 1004 |
| sync/trig 同拍 | θ=2000, ω=1024 | 2000（sync 优先）→ 2004 → 2008 → 2012 → 2016 |
| 正向回绕 | θ=8190, ω=5120 | 8190 → 18 → 38 → 58 → 78 |
| 反向 | θ=10, ω=1024, dir=0 | 10 → 6 → 2 → 8190 → 8186 |
| sync 丢失 | 继续发 trig | 保持 8186（n 封顶） |
| 运行中复位 | rst_n 脉冲 | 输出 0，trig 忽略，重新 sync 后恢复 |

## 5. 使用注意

1. `sync`/`trig` 若来自其它时钟域，模块内部已做两拍同步，但**脉冲宽度必须 ≥3 个 clk**
   （256 MHz 下 ≥12 ns）；更窄的脉冲需在源端展宽。
2. `theta_in` 允许出现 8192，内部归一为 0；`omega_in` 约定 0~5120，超范围不报错但
   增量随之变大（仍是 Q0.8 语义）。
3. `theta_out` 为同步后的寄存器输出，下游（Park 变换）直接使用，无需再打拍。
4. 若实际系统 sync 与 trig 不对齐（相位未知），本模块按「sync 时刻装载、
   之后每个 trig 外推一拍」工作，最后一个外推值保持到下一次 sync，行为自洽。
5. 本模块按当前约定 `25k/5k = 5` 设计；若同步周期内触发数变化，改参数 `N_MAX`
   即可（外推公式不变）。

## 6. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| ANGLE_MOD | 8192 | 电角度模（2^13） |
| OMEGA_FRAC | 8 | 角速度小数位 Q0.8 |
| N_MAX | 4 | 同步后允许外推的触发周期数 |

# FPGA 模块：I/f 强拖（if_drag）

对应 [docs/04 自启动算法方案](../../docs/04_自启动算法方案.md) 的 I/f 强拖阶段：
模块内部以 256 MHz 时钟分频产生 25 kHz 载波节拍，使能后把电频率按给定斜率从 0
升到目标转速对应的电频率，**每个载波周期输出电角度（8192/周）与电流幅值给定**，
供现有电流环 PI（其输出接 SVPWM 的 10000 满占空比幅值输入）与 SVPWM 使用。

## 1. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | in | 1 | 256 MHz |
| rst_n | in | 1 | 复位，低有效 |
| enable | in | 1 | 使能；拉低停拖（电流清零、角度保持），重新拉高从启动角重拖 |
| theta_start | in | 32 | 启动电角度 0~8191（来自预定位） |
| slope_in | in | 32 | 拖动斜率 Q8.8 [Hz/s 电频率] |
| target_rpm | in | 32 | 目标转速 Q8.8 [rpm 机械]（1000 → 256000） |
| theta_out | out | 32 | 电角度 0~8191，每 25 kHz 载波更新 |
| i_out | out | 32 | 电流给定 Q0.8 [A]（参数 P_I_F_Q8，默认 2560=10A，需与电流反馈定标一致） |
| done | out | 1 | 25 kHz 计算完成脉冲（1 clk，角度/电流在该沿有效） |
| reached | out | 1 | 已到达目标频率（供上层切闭环判断） |

## 2. 算法与定标（防漂移的关键）

4 对极、1000 rpm → 电频率 66.67 Hz → 每 25 kHz 周期角度增量
`66.67×8192/25000 = 21.84 LSB`——**非整数**，直接每拍加整数会漂移（每拍丢 0.84，
20 秒差一个电周期）。因此全部用分数累加：

```
频率累加器 Q0.16[Hz]：f += slope/25000        （slope_q88 × 10737 >> 20）
角度累加器 Q13.32   ：theta += f × 8192/25000 （f_q16 × 21475，全 64 位积不舍尾）
theta_out = 累加器 [44:32] 位
```

- 累加器 64 位自然回绕（2^64 = 2^19 × 2^45），角度整数位永不受损，可无限运行；
- 目标电频率换算：`f_tgt_q16 = rpm_q88 × (p×65536/60) >> 8`（p=4 时常数 4369）；
- 到达目标后频率封顶、`reached=1`，角度继续按目标频率外推（恒速强拖）。

## 3. 仿真

```bash
iverilog -o tb.out rtl/if_drag.v tb/tb_if_drag.v
vvp tb.out          # 期望最后一行 "SIM PASS"
```

TB 用 CLK_DIV=8 加速，期望值表由 Python 按 RTL 公式预计算（slope≈16673 Hz/s、
target=1000 rpm/4 对极，第 100 拍到达 66.666 Hz）：

| tick | 电频率 | theta_out | 说明 |
|---|---|---|---|
| 1 | 0.667 Hz | 1000 | 起步，首拍角度不变 |
| 50 | 33.34 Hz | 1278 | 爬坡中 |
| 99 | 66.02 Hz | 2081 | 即将到达 |
| 100 | 66.67 Hz | 2103 | **reached=1**，此后每拍 +21 LSB |
| 150 | 66.67 Hz | 3195 | 恒速强拖 |
| 200 | 66.67 Hz | 4288 | 恒速强拖 |

另验证：停拖（i_out=0、角度保持）、重新使能（回到启动角）、斜率=0（定位保持）、
运行中复位、done 脉宽恒 1 clk。

## 4. 使用注意

1. **slope_in 单位是电频率 Hz/s**（Q8.8）。机械转速斜率换算：
   `slope_Hz = slope_rpm × p / 60`。例：0.7 s 升到 1000 rpm → 1428 rpm/s →
   95.2 Hz/s → slope_in = 24373；
2. `i_out` 是**电流环 PI 的参考值**，不是 SVPWM 幅值（10000=满占空比的是 PI 输出）；
   P_I_F_Q8 必须与电流反馈的定标一致，默认 2560 = 10 A；
3. `done` 在所有状态下都按 25 kHz 节拍输出（停拖时电流给定=0、角度保持），
   电流环 PI 因此始终与载波同步，无需停机逻辑；
4. 本模块只覆盖 I/f 强拖；到达目标后由上层依据 `reached` 切换到 DSP 观测器角度
   （无扰切换见 docs/04 §3.4），切换逻辑不在本模块内；
5. `target_rpm` 运行中可改（频率封顶跟随），但阶跃下调会引起转速突降，实际使用
   建议恒定；
6. slope ≤ 800 Hz/s（Q8.8 ≤ 204800）范围内精度无损失，超出也可用但建议核对。
