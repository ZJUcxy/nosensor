# FPGA 模块：电角度外推（angle_extrapolator）

对应 [docs/02 硬件部署与SFP接口方案](../../docs/02_硬件部署与SFP接口方案.md) §3 的 P0 项「角度外推」：
DSP 每 5 kHz 下发一次电角度 θ 与角速度 ω，本模块在两次下发之间按 25 kHz 触发
逐周期外推电角度，消除 5 kHz 角度台阶在高速下造成的电流畸变。

## 1. 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | in | 1 | 256 MHz |
| rst_n | in | 1 | 复位，低有效 |
| theta_in | in | 32 | 电角度，0~8192（8192=360°，内部归一为 0） |
| omega_in | in | 32 | 角速度，无符号 Q0.8，0~20·2^8（0~5120） |
| sync | in | 1 | 5 kHz 同步（DSP 帧有效标志），脉冲宽度 ≥3 clk |
| trig | in | 1 | 25 kHz 触发，脉冲宽度 ≥3 clk |
| dir | in | 1 | 方向：1=角度加，0=角度减 |
| theta_out | out | 32 | 计算电角度，0~8191，在 sync/trig 时更新 |

## 2. 行为

```
        ┌──────────── 200 us (5 kHz) ────────────┐
sync    ─┘────────────────────────────────────────┘─
trig    ─┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──┘──  (40 us, 25 kHz)
theta_out: θin  θin+Δ  θin+2Δ  θin+3Δ  θin+4Δ   θin'(重新装载)
             n=0   n=1     n=2     n=3     n=4      n=0
Δ = (ω · n) >> 8，dir=1 为加，dir=0 为减；结果对 8192 取模
```

1. **sync 上升沿**：锁存 `theta_in / omega_in / dir`，`theta_out = theta_in`（8192 归一为 0），
   触发周期计数 `n = 0`。若 sync 与 trig 同拍到达，sync 优先。
2. **sync 之后的每个 trig 上升沿**：`n = n+1`（上限 4），
   `theta_out = theta_in_latched ± (ω_latched·n >> 8)`，按 dir 加减，回绕到 0~8191。
3. 25 kHz = 5×5 kHz：每个同步周期内第 1 个触发与同步对齐（装载），
   之后 **4 个触发各外推一拍（n=1..4）**，即「同步后四个周期外推」。
4. sync 丢失时 n 封顶在 4，角度保持最后外推值不漂移，待下一个 sync 重新装载；
   复位后、首次 sync 之前，trig 被忽略，输出保持 0。

## 3. 计算与位宽

- 乘法：`ω(≤5120, 13bit) × n(4bit) → 17bit`，右移 8 位得增量（Q0.8 → 整数）。
- 单次增量最大 `5120×4>>8 = 80` LSB，远小于 8192，回绕只需一次加减。
- 实现为**单周期组合计算 + 一拍寄存器**，在 256 MHz 下时序余量充足；
  资源约 1 个 32×4 乘法器 + 几十个触发器，无需 DSP 块（LUT 即可）。

## 4. 仿真

```bash
iverilog -o tb.out rtl/angle_extrapolator.v tb/tb_angle_extrapolator.v
vvp tb.out          # 期望最后一行 "SIM PASS"
```

关键验证点（与 testbench 中场景一一对应）：

| 场景 | 输入 | 输出序列 |
|---|---|---|
| 装载+外推 | θ=1000, ω=256, dir=1 | 1000 → 1001 → 1002 → 1003 → 1004 |
| sync/trig 同拍 | θ=2000, ω=1024 | 2000（sync 优先）→ 2004 → 2008 → 2012 → 2016 |
| 正向回绕 | θ=8190, ω=5120 | 8190 → 18 → 38 → 58 → 78 |
| 反向 | θ=10, ω=1024, dir=0 | 10 → 6 → 2 → 8190 → 8186 |
| sync 丢失 | 继续发 trig | 保持 8186（n 封顶） |
| 运行中复位 | rst_n 脉冲 | 输出 0，trig 忽略，重新 sync 后恢复 |

## 5. 使用注意

1. `sync`/`trig` 若来自其它时钟域，模块内部已做两拍同步，但**脉冲宽度必须 ≥3 个 clk**
   （256 MHz 下 ≥12 ns）；更窄的脉冲需在源端展宽。
2. `theta_in` 允许出现 8192，内部归一为 0；`omega_in` 约定 0~5120，超范围不报错但
   增量随之变大（仍是 Q0.8 语义）。
3. `theta_out` 为同步后的寄存器输出，下游（Park 变换）直接使用，无需再打拍。
4. 若实际系统 sync 与 trig 不对齐（相位未知），本模块按「sync 时刻装载、
   之后每个 trig 外推一拍」工作，最后一个外推值保持到下一次 sync，行为自洽。
5. 本模块按当前约定 `25k/5k = 5` 设计；若同步周期内触发数变化，改参数 `N_MAX`
   即可（外推公式不变）。

## 6. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| ANGLE_MOD | 8192 | 电角度模（2^13） |
| OMEGA_FRAC | 8 | 角速度小数位 Q0.8 |
| N_MAX | 4 | 同步后允许外推的触发周期数 |
