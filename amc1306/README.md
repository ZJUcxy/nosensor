# AMC1306 功能仿真（MATLAB）

TI 隔离式 ΔΣ 调制器 AMC1306 的功能建模与 sinc3 抽取滤波分析：
**群延时 vs 完全建立时间** 在三相稳态与阶跃工况下的区别，以及群延时补偿算法方案。

## 文件

| 文件 | 说明 |
|---|---|
| `model_amc1306.m` | 功能模型：二阶 ΔΣ 调制器 → Manchester 解码 → sinc3(CIC) 抽取 |
| `analysis_main.m` | 主分析脚本（自检/稳态/阶跃/三种补偿方案） |
| `群延时分析与补偿方案.md` | 结论与补偿算法方案（含本项目落点） |
| `results/` | 仿真图（运行后生成） |

## 运行

```matlab
cd amc1306
matlab -batch "analysis_main"      % 命令行
% 或在 MATLAB 中直接 run analysis_main
```

## 模型与参数

```
 u(t) ──► [二阶ΔΣ调制器 @20MHz] ──► [Manchester解码] ──► [sinc3 抽取 OSR=256] ──► y @78.125kHz
            (单比特流 ±1)             (+1 clk 延迟)         (3级积分+256抽取+3级梳状)
```

| 参数 | 值 |
|---|---|
| 调制器时钟 fclk | 20 MHz |
| sinc3 抽取率 OSR | 256 |
| 输出速率 fs_out | 78.125 kHz（输出周期 12.8 µs） |
| 链前延迟 lat_clk（调制器流水线+Manchester） | 2 clk = 0.1 µs（模型假设，需硬件标定） |
| sinc3 群延时 | (3·OSR−3)/2 = 382.5 clk = **19.125 µs** |
| sinc3 完全建立 | 3·OSR−2 = 766 clk = **38.3 µs** |
| 总群延时 / 总完全建立 | **19.225 µs / 38.4 µs（恰好 2 倍）** |

## 结论速览（详见方案文档）

1. **三相稳态**：三个通道群延时一致（同一硬件/同一滤波器），三相保持平衡；但对电流矢量
   产生整体旋转 `δ = ωe·τ_total`：50 Hz→0.35°、200 Hz→1.38°、1 kHz→6.9°，须用测量侧
   角度后移（θ̂−ω̂·τ）补偿。
2. **阶跃工况**：50% 建立点在群延时（19.2 µs），100% 建立需 38.35 µs——瞬态工况的"有效延迟"
   比稳态相位延迟大 2 倍，不能用同一个数补偿。
3. **输出网格量化**：抽取输出只在 12.8 µs 整数倍更新，阶跃相对抽取网格的相位使观测量
   有 0~12.8 µs 的不确定性，需要在系统级约定（FPGA 侧做 200 µs 同步平均即可消除）。
4. **推荐补偿方案**：FPGA 内 2 抽头均衡器 [0.5020, 0.4980] 把总时延"整数化"为 2 拍
   （25.6 µs）→ DSP 按整数拍测量角后移（θ̂−ω̂·2·Ts_out）补偿；阶跃/保护工况叠加
   一阶预测外推（噪声代价实测 2.46 倍，白噪声上界 √(1+2D²)=3）。
